# Netflix Data Analysis

## Project Objective
Analyze Netflix movies and TV shows dataset to identify content trends, genre popularity, release patterns, and country-wise content distribution using Python data analysis and visualization techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset Features
- Type (Movie / TV Show)
- Title
- Director
- Country
- Release Year
- Rating
- Duration
- Genre

## Analysis Performed
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Content Type Analysis
- Country-wise Content Analysis
- Genre Analysis
- Release Trend Analysis
- Rating Distribution Analysis

## Key Insights
- Netflix contains more Movies than TV Shows.
- Content releases increased significantly after 2015.
- United States contributes the highest amount of Netflix content.
- Drama and International genres are highly popular on Netflix.
- Netflix content growth has rapidly increased in recent years.

## Tools Used
- Google Colab
- GitHub

## Conclusion
This project helped in understanding Netflix content trends and audience preferences using data analysis and visualization techniques. The analysis provided insights into content distribution, genre popularity, and release growth patterns.
